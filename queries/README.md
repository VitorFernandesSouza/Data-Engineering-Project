# Queries

Esta pasta reúne os scripts SQL reutilizáveis e as views analíticas do projeto.

## Estrutura

- `ecommerce_views/`: views principais para consumo analítico e do Power BI.
- `ad_hoc/`: consultas temporárias para exploração e validação.
- `reports/`: queries para métricas e relatórios específicos.

## Convenções

- nomes em snake_case;
- comentários curtos e claros;
- organização por domínio e finalidade;
- priorizar views reutilizáveis em vez de consultas duplicadas.
